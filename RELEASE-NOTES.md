# Agent Looper 1.0 — Windows

Native Windows x64 loop pedal with Single + Destructive startup defaults, optional dual loopers and separate layers, seamless overdubbing, Undo/Redo, input-triggered recording, quantized starts, optional count-in and click, A-to-B routing, and MIDI-assignable transports and knobs.

Edit loop regions with waveform handles and scroll-wheel zoom. Change pitch, stretch and filter during playback; Warp aligns layers in layered mode. Master FX include Hall/Room reverb with tone, synced Delay/Ping-Pong/POTS, Granular/Clouds/Cloud Delay, Freeze, grain dry/wet and a lowpass/highpass master filter.

Rounded custom controls, collapsible editing and FX, app-styled scrolling, immediate imported-waveform refresh, and immersive fullscreen (F11; Escape or EXIT to leave).

Extract the entire Windows ZIP and run Agent-Looper.exe. Keep the DLLs, tools and license folders alongside it. Requires Windows x64 and .NET Framework 4.7.2 or later. Import supports up to ten minutes per file, including MP3 and audio from supported video files through Windows codecs. Export is 48 kHz stereo 32-bit float WAV.

This release contains Windows software only. No Android APK or app bundle is distributed.

Validation: Windows UI suite passed, including dropdowns, FX controls, import refresh, custom scrolling, fullscreen, and Single + Destructive layout/history checks. No new audio algorithms were introduced for the 1.0 version promotion.
